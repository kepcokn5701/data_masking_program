# 📗 데이터 보안처리 프로그램 — 아주 쉬운 사용설명서

> 이 설명서는 **컴퓨터를 잘 몰라도** 누구나 따라 할 수 있게 만들었습니다.
> 그림(화면 모양)을 보면서 **하나씩 그대로 따라 하시면 됩니다.**

---

## 📌 먼저, 딱 한 줄 요약

> **회사 파일을 인터넷망으로 내보내기 전에, 파일 속 개인정보(이름·전화번호 등)를 별표(\*)로 가린
> "안전한 사본"을 만들어 주는 프로그램**입니다. 파일을 마우스 오른쪽 버튼으로 누르기만 하면 됩니다.

## 1. 왜 이걸 해야 하나요? (아주 중요합니다)

### 🔑 개인정보는 '집 열쇠'와 같습니다
이름·주민등록번호·전화번호·주소 같은 **개인정보**는, 나쁜 사람 손에 들어가면
**보이스피싱, 명의도용, 사기**에 바로 쓰입니다. 마치 **집 열쇠를 길에 흘리는 것**과 같아요.

### 🧱 회사 컴퓨터는 '두 개의 방'으로 나뉘어 있습니다
- **업무망** = 회사 안쪽 방 (안전하게 잠겨 있음)
- **인터넷망** = 바깥 세상과 연결된 방

업무망에서 인터넷망으로 파일을 보내는 것(**FTC**)은, **안쪽 방의 서류를 바깥으로 내보내는 것**입니다.
이때 개인정보가 그대로 적힌 서류를 내보내면, 바깥으로 **새어 나갈 위험**이 생깁니다.

### ⚖️ 나라(법·국정원)가 "가리고 내보내라"고 정했습니다
- **개인정보보호법**: 개인정보를 다룰 땐 **안전하게 보호할 의무**가 있습니다. 어기면 회사가 **과징금·처벌**을 받습니다.
- **국정원(N2SF, 국가 망 보안체계)**: 국정원은 **나라의 사이버 안보**를 지키는 곳이라, 공공기관이 망(네트워크) 사이로
  자료를 주고받을 때 **안전하게 관리하도록** 규칙을 정합니다. **한전은 공기업이라 특히 엄격하게** 지켜야 합니다.

> 한마디로: **"개인정보가 든 파일을 밖으로 보낼 땐, 개인정보를 가린 뒤 보내라"** 는 것이 법과 규정입니다.
> 이 프로그램이 그 "가리는" 일을 자동으로 해 줍니다.

### 🩹 '마스킹'이 뭔가요?
**마스킹 = 개인정보를 별표(\*)로 가려서 못 알아보게 만드는 것**입니다. (한 번 가리면 되돌릴 수 없습니다.)

| 원래 내용 | 마스킹 후 |
|---|---|
| 홍길동 | 홍\*동 |
| 010-1234-5678 | 010-\*\*\*\*-5678 |
| 900101-1234567 | \*\*\*\*\*\*-\*\*\*\*\*\*\* |

## 2. 처음 준비 (딱 한 번만 하면 됩니다)

**1단계.** 받은 프로그램 파일 **`데이터 보안처리 프로그램`** 을 **더블클릭**해서 실행합니다.
- 따로 설치 과정은 없습니다. 그냥 두 번 누르면 됩니다.
- ⏳ **처음 실행은 10~20초쯤 걸립니다.** 창이 바로 안 떠도 조금만 기다려 주세요.

**2단계.** 실행되면, 화면 **오른쪽 아래 시계 옆**에 자물쇠 모양 아이콘(🔒)이 생깁니다.

```
                                   화면 오른쪽 아래 (시계 옆)
                                   ┌──────────────────────┐
                                   │   ∧  🔒  📶  🔊  9:41  │
                                   │       ↑                │
                                   │   이 자물쇠 아이콘      │
                                   └──────────────────────┘
```

**3단계.** 그 **자물쇠 아이콘을 마우스 오른쪽 버튼으로 클릭**하면 아래 메뉴가 나옵니다.
여기서 **[오른쪽클릭에 '마스킹 사본 만들기' 추가]** 를 한 번 눌러 주세요.

```
   ┌─────────────────────────────────────────┐
   │  마스킹 도구 열기                          │
   │  ─────────────────────────────           │
   │  자동 마스킹 폴더 열기 (넣으면 자동 처리)    │
   │  완료된 파일 폴더 열기                      │
   │  자동 마스킹 잠시 멈춤                      │
   │  ─────────────────────────────           │
   │  오른쪽클릭에 '마스킹 사본 만들기' 추가  ← 클릭! │
   │  오른쪽클릭 메뉴에서 빼기                   │
   │  ─────────────────────────────           │
   │  종료                                     │
   └─────────────────────────────────────────┘
```

✅ 이제 준비 끝! "추가되었습니다"라는 작은 알림이 뜨면 성공입니다.

## 3. 가장 쉬운 사용법 — 오른쪽 버튼 3단계 ⭐

개인정보가 든 엑셀 파일을 인터넷망으로 보내야 할 때:

**① 파일 위에서 마우스 오른쪽 버튼을 누릅니다.**

```
   📄 직원명부.xlsx   ← 이 파일 위에서 오른쪽 버튼 클릭
```

**② 나오는 메뉴에서 [🔒 개인정보 마스킹 사본 만들기] 를 누릅니다.**

```
   ┌──────────────────────────────────┐
   │  열기(O)                          │
   │  인쇄(P)                          │
   │  🔒 개인정보 마스킹 사본 만들기  ← 클릭! │
   │  잘라내기(T)                       │
   │  복사(C)                          │
   │  ...                             │
   └──────────────────────────────────┘
```

**③ 잠시 뒤, 아래 같은 안내창이 뜨고, 같은 폴더에 "\_마스킹" 파일이 새로 생깁니다.**

```
   ┌──────────────────────────────────────┐
   │  ✅ 마스킹 사본 생성 완료               │
   │                                      │
   │  개인정보를 가린 사본을 만들었습니다.    │
   │                                      │
   │  만들어진 파일:                        │
   │   직원명부_마스킹.xlsx                 │
   │  (원본과 같은 폴더에 새로 생겼어요)      │
   │                                      │
   │  가린 개인정보 (총 12건):              │
   │    · 이름 × 5건                       │
   │    · 전화번호 × 4건                    │
   │    · 주민등록번호 × 3건                │
   │                                      │
   │  ▶ FTC로는 이 '_마스킹' 파일을 내보내세요. │
   │                          [ 확인 ]     │
   └──────────────────────────────────────┘
```

```
   폴더를 보면 파일이 두 개가 됩니다:

   📄 직원명부.xlsx          ← 원본 (개인정보 그대로)  ❌ 이건 내보내지 마세요!
   📄 직원명부_마스킹.xlsx    ← 새로 생긴 안전한 사본    ✅ 이걸 FTC로 내보내세요!
```

**끝입니다!** FTC로는 반드시 **"\_마스킹"이 붙은 파일**을 내보내세요.

## 4. 내보내기 전, 꼭 확인하세요 ✅ (1분이면 됩니다)

이 프로그램은 자동으로 하다 보니 **가끔 놓치거나 잘못 가릴 수 있습니다.** 그래서 보내기 전에:

1. **파일 이름에 `_마스킹` 이 붙어 있는지** 확인하세요. (원본을 실수로 보내면 큰일!)
2. 그 파일을 열어서 **개인정보가 별표(\*)로 잘 가려졌는지** 눈으로 한 번 훑어보세요.
3. 엑셀 아래쪽 **[분류리포트]** 라는 시트를 누르면, **무엇을 왜 가렸는지 목록**으로 볼 수 있습니다.

```
   엑셀 아래쪽 시트 탭:
   [ 마스킹결과 ]  [ 분류리포트 ]  [ N2SF근거 ]
                      ↑ 여기를 누르면 무엇을 가렸는지 나옵니다
```

## 5. 안 가려진 개인정보가 있을 때 — "항상 가릴 칸" 정하기

이 프로그램은 **글자 모양을 보고 스스로** 이름·주소·전화번호를 찾아냅니다.
(예: "○○시 ○○구 ○○동" 처럼 생기면 주소인 줄 압니다. 칸 제목을 몰라도 됩니다.)

하지만 **우리 회사에만 있는 특별한 칸**(예: `계약번호`, `상호`)은 자동으로 못 알아챌 수 있어요.
그럴 땐 **한 번만 알려주면 다음부터 기억**합니다:

**1단계.** 자물쇠 아이콘 더블클릭 → 도구 창 열기 → 파일을 하나 엽니다.
**2단계.** 창 위쪽의 **[📌 항상 마스킹할 칸 정하기]** 버튼을 누릅니다.
**3단계.** **가릴 칸을 고르고 → 가리는 방법을 고른 뒤 → [＋ 추가]** 를 누릅니다.

```
   ┌──────────────────────────────────────────┐
   │  📌 항상 마스킹할 칸 정하기                  │
   │                                          │
   │  지금까지 정한 칸:                            │
   │   ‘계약번호’ 칸 → 뒤 4자리만 남김             │
   │                  1234567890 → ******7890  [삭제] │
   │                                             │
   │  새로 정하기:                                │
   │   칸: [고객번호 ▾] 방법: [뒤 N자리만 남김 ▾]    │
   │                                 [ ＋ 추가 ]  │
   │   남길 자릿수 : [ 4 ]  (0 ~ 12 사이)          │
   │   미리보기:  0912345678  →  ******5678        │
   └─────────────────────────────────────────────┘
```

💡 **방법을 바꿀 때마다 맨 아래 `미리보기` 가 즉시 바뀝니다.**
용어를 몰라도 됩니다 — **결과가 마음에 드는 것을 고르면 됩니다.**
(엉뚱한 방법을 고르면 `0912345678 → 091*******@` 처럼 이상하게 나오니 바로 알 수 있어요.)

이제부터 그 칸은 **항상 자동으로 가려집니다.** (한 번만 정하면 계속 기억해요.)

### 처리 방법 고르기 — 두 갈래가 있어요

**① 글자 가리기** — 개인정보를 없애는 방법입니다.

| 방법 | 결과 예시 | 이럴 때 씁니다 |
|---|---|---|
| **전체 가림** | `한빛산업` → `****` | 상호·사유처럼 통째로 감춰야 할 때 |
| **숫자 전부 가림** | `850312-1123456` → `******-*******` | 주민번호·계좌처럼 **절대 되살리면 안 되는** 번호 |
| **뒤 N자리만 남김** | `99-1234-5678` → `**-****-5678` | 고객번호·계약번호처럼 **나중에 대조해야 하는** 번호 |

**② 숫자 가상화** — 값을 지우지 않고 **비슷한 가짜 값**으로 바꿉니다.
가려버리면 분석을 못 하니까, **평균·추세는 살리고 개인의 실제 값만 감추는** 방법입니다.

| 방법 | 결과 예시 | 이럴 때 씁니다 |
|---|---|---|
| **무작위 오차 ±N%** | `350.5` → `338.2` / `361.1` / `326.0` | 사용량처럼 **추세 분석이 필요한** 숫자 |
| **N단위로 뭉개기** | `3` `7` `22` → `5` `5` `20` | 계약전력처럼 **비슷한 것끼리 묶어도 되는** 숫자 |
| **그대로 두기** | `3` → `3` | 이 칸은 건드리지 않겠다고 **분명히 정해둘 때** |

> 💡 **무작위 오차는 줄마다 값이 다릅니다.** 이게 핵심입니다.
> 모든 줄에 똑같이 +10%를 하면 자기 집 사용량만 알아도 나눠서 전부 되살릴 수 있습니다.
> 줄마다 제각각 흔들어야 되돌릴 수 없고, 그러면서도 전체 평균은 거의 그대로 유지됩니다.

### 🎚️ 방법마다 '숫자 조절칸'이 나옵니다

방법을 고르면 그 아래에 **조절칸**이 나타납니다. 칸마다 사정이 다르기 때문입니다.

```
   방법: [뒤 N자리만 남김 ▾]     남길 자릿수 : [ 4 ]  (0 ~ 12 사이)
   미리보기:   0912345678  →  ******5678
```

**같은 방법이라도 숫자를 바꾸면 결과가 달라집니다.**

| 칸 | 자릿수 4로 하면 | 자릿수 2로 하면 |
|---|---|---|
| 고객번호 `0912345678` (10자리) | `******5678` ✅ | `********78` |
| 사업소코드 `51440` (5자리) | `*1440` ❌ 한 자리만 가려짐 | `***40` ✅ |

**짧은 칸에 큰 숫자를 넣으면 거의 안 가려집니다.** 반드시 **미리보기를 보고** 정하세요.

### ❗ 왜 고객번호는 전부 가리지 않나요?

전부 가리면 (`**-****-****`) 모든 줄이 똑같아 보여서, **파일을 받은 담당자조차 어느 줄이 어느 고객인지
구분할 수 없습니다.** 그러면 "지원금 받은 고객 / 안 받은 고객 가려내기" 같은 일 자체를 못 하게 됩니다.

그래서 고객번호는 **뒤 4자리만 남깁니다.**
- 앞 2자리(지역·사업소 코드)와 가운데 4자리는 가리므로 **어느 지역 누구인지 알 수 없고,**
- 뒤 4자리는 남으므로 **줄과 줄을 구분하는 꼬리표**로는 쓸 수 있습니다.

> ⚠️ **주의 — 수백 줄이 넘는 큰 파일에서는** 우연히 뒤 4자리가 같은 고객이 생길 수 있습니다.
> (약 300줄이면 같은 꼬리표가 한 쌍 나올 가능성이 절반쯤 됩니다.)
> 대조 결과가 이상하면 그 줄들이 겹친 건 아닌지 확인해 주세요.

## 6. 다른 방법도 있어요 (원하는 사람만)

### 방법 2 — 창에서 하나씩 확인하며 하기
1. 자물쇠 아이콘 **더블클릭** → 도구 창이 열립니다.
2. **[파일 열기]** 로 엑셀을 고릅니다.
3. 가릴 칸이 **자동으로 체크**되어 나옵니다. 확인하고 조정할 수 있어요.
4. 아래 **확인 체크** 후 **[마스킹 실행 및 저장]** 을 누릅니다.

### 방법 3 — 폴더에 넣기만 하면 자동
1. 자물쇠 아이콘 오른쪽 클릭 → **[자동 마스킹 폴더 열기]**
2. 그 폴더에 엑셀 파일을 **끌어다 넣으면**, 자동으로 마스킹되어 **[완료된 파일 폴더]** 에 결과가 생깁니다.

## 8. 자주 묻는 질문

**Q. 어려운 프로그램을 따로 깔아야 하나요?**
> 아니요. 받은 파일 하나만 실행하면 됩니다.

**Q. 원본 파일이 없어지거나 바뀌나요?**
> 아니요. 원본은 그대로 있고, 옆에 **"\_마스킹" 사본이 새로 생깁니다.**

**Q. 오른쪽 버튼 메뉴에 항목이 안 보여요.**
> 위 **2. 처음 준비**의 3단계(자물쇠 → '마스킹 사본 만들기' 추가)를 한 번 해 주세요.

**Q. 개인정보가 아닌데 가려졌어요 / 가려야 하는데 안 가려졌어요.**
> 자동이라 가끔 그럴 수 있어요. **5번(항상 가릴 칸 정하기)** 이나 **방법 2(창에서 조정)** 로 고칠 수 있습니다.

**Q. 처음 실행이 느려요. 고장인가요?**
> 정상입니다. 처음만 조금 느리고, 두 번째부터 빨라집니다.

**Q. 내가 언제 뭘 했는지 기록이 남나요?**
> "누가·언제·어떤 파일을·몇 건 가렸는지"만 남습니다. **파일 속 실제 개인정보 내용은 절대 기록하지 않습니다.**
