🔒 엑셀 개인정보 마스킹 도구

엑셀 파일의 개인정보(이름·전화번호·이메일·주민번호·카드·계좌·주소 등)를 자동 감지하여 마스킹합니다. 한 셀에 여러 정보가 섞여 있어도 각각 마스킹합니다. Python 설치 없이 더블클릭으로 바로 실행하세요.

📘 자세한 동작 원리와 등급 분류(N2SF 참고)는 교육자료를 확인하세요.

Windows 10/11 · 약 43 MB
📥 다운로드 (최신 버전)
더블클릭으로 실행 · 별도 설치 불필요

📋 사용 방법

1단계
위 버튼으로 exel_masking.exe 다운로드
2단계
다운로드한 파일을 더블클릭하여 실행
3단계
"파일 열기" 클릭 → 엑셀 파일(.xlsx) 선택
4단계
자동 감지된 마스킹 항목 확인 (수정 가능)
5단계
"마스킹 실행 및 저장" → 저장 위치 선택

🎯 자동 감지 및 마스킹 예시

  • 이름: 홍길동 → 홍*동
  • 전화번호: 010-1234-5678 → 010-****-5678
  • 이메일: hong@gmail.com → ho**@gmail.com
  • 주민등록번호: 900101-1234567 → ******-*******
  • 주소: 서울시 강남구 역삼동 → 서울시 *** ***
  • 한 셀 다중 정보: 홍길동 010-1234-5678 → 홍*동 010-****-5678
⚠️ 첫 실행 시 안내: Windows Defender나 백신 프로그램이 PyInstaller로 패키징된 exe를 의심 파일로 잡을 수 있습니다. 정상 파일이니 "허용" 또는 "예외 등록"을 선택해 주세요. 사내 EDR에서 차단된다면 IT팀에 화이트리스트 등록을 요청하세요.
