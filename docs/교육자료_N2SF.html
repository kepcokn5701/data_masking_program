핵심은 민감정보 마스킹 · N2SF 등급 분류는 향후 전환 대비 참고 레이어

📌 이 도구의 본질은 "마스킹"입니다. 민감정보를 빠짐없이 가리는 것이 1차 목적이고, 아래 N2SF(국가 망 보안체계) C/S/O 등급 분류는 지금 당장의 의무 기준이 아니라 향후 망분리→N2SF 전환에 대비한 참고용 분류 체계입니다.

1. (참고) N2SF란 무엇인가

아래 내용은 향후 전환 대비 참고 자료입니다. 현재 도구의 동작 핵심은 4장 "마스킹"입니다.

N2SF(National Network Security Framework, 국가 망 보안체계)는 국가정보원(NIS)이 발표한 신(新) 보안체계입니다. 기존 공공부문의 경직된 망분리(網分離) 정책 대신, AI·클라우드 등 신기술을 안전하게 활용할 수 있도록 데이터 중요도 기반의 다층 보안으로 전환하는 것이 핵심입니다.

2. 데이터 3등급: C · S · O

각 기관은 정보공개법 등 관련 법률이 규정한 비공개정보를 중요도에 따라 기밀(C) 또는 민감(S)으로, 그 외 모든 정보를 공개(O)로 분류합니다.

등급정의본 도구의 처리예시 정보
C 기밀
Classified		 비공개정보 중 중요도가 높은 고유식별·금융정보 완전 마스킹 주민등록번호, 신용카드, 계좌, 여권, 운전면허
S 민감
Sensitive		 공개 시 개인·국가 이익 침해가 우려되는 식별 가능 정보 부분 마스킹 이름, 전화번호, 이메일, 주소, 생년월일, 차량번호
O 공개
Open		 기밀·민감을 제외한 모든 정보 원본 유지 부서명, 직급, 일반 텍스트·숫자

3. 본 도구는 어떻게 분류·마스킹하는가

업로드된 엑셀의 모든 셀을 스캔하여, 정해진 규칙에 맞는 정보를 찾아 등급별로 차등 마스킹합니다. 한 셀에 여러 정보가 섞여 있어도 각각 탐지합니다.

4. 모든 결과는 "설명 가능"해야 한다

규제·정책 기반 도구의 신뢰는 "왜 이렇게 분류·마스킹했는가"를 댈 수 있는가에서 나옵니다. 본 도구는 이를 위해:

  • 저장 파일에 [분류리포트] 시트 — 컬럼별 탐지 유형·등급·건수·탐지 근거 기록
  • 저장 파일에 [N2SF근거] 시트 — 적용 기준·등급 정의·원문 확인 안내·참고 동향 기록(외부 URL 없음)
  • 앱 내 [ℹ️ N2SF 기준·근거 보기] — 등급 정의와 원문 확인처(국정원 홈페이지) 안내

⚖️ 이름 탐지의 보수적 설계 (오탐 방지)

자유 텍스트 속 한글 이름은 일반 명사와 구분이 어렵습니다(예: "차량", "여권"). 잘못된 마스킹을 막기 위해 이름은 다음 근거가 있을 때만 탐지합니다.

  1. 이름 컬럼으로 판정된 컬럼의 값 (헤더에 '이름/성명/담당자' 등)
  2. 이름 뒤 호칭·직함 동반 (예: 박영희 과장)
  3. 연락처/식별정보와 인접 (예: 홍길동 010-…)
그래서 차량 12가3456의 "차량"이나 여권 M12345678의 "여권"은 이름으로 오인하지 않습니다. 라벨 단어는 그대로 두고 실제 값만 마스킹합니다.

5. 사용 절차

  1. 파일 열기 → 엑셀(.xlsx) 선택
  2. 자동 분류 결과 확인 — 컬럼별 C/S/O 배지·탐지유형·미리보기(원본→마스킹)
  3. 마스킹할 컬럼 체크 조정 (공개(O)는 기본 해제)
  4. 마스킹 실행 및 저장 → 결과/리포트/근거 3시트 저장

6. 이해도 점검 퀴즈

Q1. 주민등록번호와 이메일은 각각 어떤 등급인가?

주민등록번호 = 기밀(C), 완전 마스킹 / 이메일 = 민감(S), 부분 마스킹

Q2. "홍길동 010-1234-5678" 한 셀은 어떻게 처리되나?

이름과 전화번호를 각각 탐지하여 홍*동 010-****-5678로 마스킹됩니다.

Q3. "차량 12가3456"에서 "차량"이 이름으로 마스킹되지 않는 이유는?

이름은 이름컬럼/직함/연락처 인접 근거가 있을 때만 탐지하기 때문입니다. "차량"은 그 근거가 없어 제외됩니다.

Q4. N2SF 가이드라인 정식판 1.0은 언제 공개되었나?

2025년 9월(CSK 2025에서 발표, 9월 30일 정식 공개). 초안은 2025년 1월. 전국 일괄 시행일은 단일 날짜로 공표되지 않았습니다.

정식 근거(원문)는 국정원 홈페이지에서 확인할 수 있으며, 언론·보도자료는 참고 동향입니다.
외부 링크는 업무망(폐쇄망) 환경을 고려해 첨부하지 않았습니다.
