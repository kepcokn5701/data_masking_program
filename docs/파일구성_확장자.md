## 2. 소스코드 (`.py`) — 프로그램의 본체

| 파일 | 역할 |
|------|------|
| `masking_engine.py` | **공용 마스킹 엔진**(규칙·등급·오탐확률). 데스크톱·웹이 함께 import. |
| `excel_masking.py` | **데스크톱 GUI**(tkinter). 엔진을 불러 화면만 담당. |
| `web/app.py` | **웹서버**(Flask). 같은 엔진을 불러 브라우저로 제공. |
| `web/usage_logger.py` | 사용 이력 로깅 유틸(JSONL append). |

> 규칙·등급 변경은 항상 `masking_engine.py` **한 곳만** 수정하면 데스크톱·웹에 동시 반영.

## 4. 실행·빌드 (`.bat`, `.txt`)

| 파일 | 역할 |
|------|------|
| `web/실행.bat` | 웹서버 실행(패키지 설치 후 `app.py` 기동). |
| `빌드_실행.bat` | 데스크톱 `.exe` 빌드(PyInstaller). |
| `web/requirements.txt` | 웹 실행에 필요한 패키지 목록(pandas·openpyxl·flask·waitress). |

## 5. 실행·빌드 시 "생성"되는 것 (저장소 미포함)

| 확장자 | 언제 생기나 | 비고 |
|--------|------------|------|
| `.exe` | `빌드_실행.bat` 실행 시 `dist/`에 | 데스크톱 배포본 |
| `.spec`, `build/`, `dist/` | PyInstaller 빌드 중간물 | gitignore |
| `.pyc`, `__pycache__/` | Python 실행 캐시 | gitignore |
| `.xlsx` | 사용자가 올린/내려받은 데이터 | 개인정보 가능 → 깃 금지 |
| `.zip` | 웹에서 여러 파일 마스킹 시 | 다운로드 산출 |
| `.jsonl` | 웹 사용 시 `web/logs/`에 | **개인정보 본문 없음**(메타데이터만), gitignore |

## 6. 런타임 의존성 (사내망 이관 시 함께 챙길 것)

- **Python 3.x** (데스크톱·웹 공통)
- 패키지: `openpyxl` (엑셀 입출력), `flask`·`waitress` (웹), `pyinstaller` (exe 빌드)
  - pandas·numpy는 제거됨(용량·의존성 축소 → exe 20MB 이내, .xlsx만 지원)
- 폐쇄망이라 `pip install`이 막히면: 인터넷 PC에서 **휠(`.whl`) 파일을 내려받아 오프라인 설치**하거나, 데스크톱은 **`.exe` 단일 배포본**(Python 불필요)으로 전달.

> 정리: **저장소에는 `.py/.html/.md/.bat/.txt`만**, **배포본은 `.exe`(데스크톱) 또는 웹서버 구동**, **데이터·로그(`.xlsx/.zip/.jsonl`)는 깃 제외**.
