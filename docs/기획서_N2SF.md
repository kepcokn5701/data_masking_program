# 엑셀 N2SF 정보 분류·마스킹 도구 — 기획서

## 1. 프로젝트의 본질

> **핵심은 "민감정보 마스킹"이다.** 업로드된 엑셀에서 민감정보를 빠짐없이 가리는 것이 1차 목적이며,
> N2SF의 C / S / O 등급 분류는 **향후 망분리 → N2SF 전환에 대비한 참고용 분류 레이어**다.

따라서 우선순위는 **① 마스킹 정확도·사용성**, **② N2SF 등급 분류(부가 가치)** 순이다.
N2SF는 지금 당장의 의무 기준이 아니라 "앞으로 이렇게 바뀔 수 있다"는 참고 체계이므로,
분류 표시는 보조적으로 제공하고 마스킹 누락이 없도록 하는 데 집중한다.

### N2SF 등급 정의
| 등급 | 의미 | 처리 정책 |
|------|------|-----------|
| **C** (Classified / 기밀) | 유출 시 심각한 피해. 고유식별정보·금융정보 | **완전 마스킹** |
| **S** (Sensitive / 민감) | 개인 식별 가능 정보 | **부분 마스킹** |
| **O** (Open / 공개) | 비식별·일반 정보 | **원본 유지** |

## 2. 정보 유형 → 등급 → 마스킹 규칙

| 정보 유형 | 등급 | 탐지 방식 | 마스킹 예시 |
|-----------|:---:|-----------|-------------|
| 주민등록번호 | **C** | `\d{6}-?\d{7}` + 검증 | `900101-1234567` → `******-*******` |
| 외국인등록번호 | **C** | 주민번호와 동일 형식 | `******-*******` |
| 여권번호 | **C** | `[A-Z]\d{8}` | `M********` |
| 운전면허번호 | **C** | `\d{2}-?\d{2}-?\d{6}-?\d{2}` | 전체 `*` |
| 신용카드번호 | **C** | `\d{4}-?\d{4}-?\d{4}-?\d{4}` (Luhn) | `****-****-****-****` |
| 계좌번호 | **C** | 숫자 10~14자리 패턴 | 전체 `*` |
| 이름 | **S** | 컬럼 판정 + 성씨사전 | `홍길동` → `홍*동`, `김철` → `김*` |
| 휴대폰/전화 | **S** | `0\d{1,2}-?\d{3,4}-?\d{4}` | `010-****-5678` |
| 이메일 | **S** | RFC 약식 정규식 | `ho**@gmail.com` |
| 주소 | **S** | 시/도 키워드 패턴 | `서울시 *** ***` |
| 생년월일 | **S** | `\d{4}[-.]\d{1,2}[-.]\d{1,2}` | `1990-**-**` |
| 차량번호 | **S** | `\d{2,3}[가-힣]\d{4}` | `**가****` |
| 그 외 전부 | **O** | (미매칭) | 원본 유지 |

> 등급/규칙은 코드 상단 `ENTITY_RULES` 한 곳에 데이터로 정의 → 정책 변경 시 표만 수정.

## 3. 핵심 설계 변경 — "컬럼 유형" → "셀 내부 엔티티 스캔"

### 기존 한계
- `detect_column_type()` 가 **컬럼당 단일 유형**만 판정 → 컬럼당 함수 1개 적용.
- 한 셀에 `홍길동 010-1234-5678` 처럼 **여러 정보가 섞이면 일부만 마스킹**되거나 전부 누락.

### 신규 방식 (전체 셀 자동 스캔)
```
각 셀(str) 마다:
  1. 모든 ENTITY_RULES 정규식으로 매칭 위치(span)를 전부 수집
  2. 겹치는 매칭은 (등급 우선순위 C>S) → (길이) 순으로 충돌 해소
  3. 확정된 span 들을 등급별 마스킹 함수로 치환하여 셀 문자열 재조립
  4. 셀 내 최고 등급을 그 셀의 분류 등급으로 기록
```
- **한 셀에 이름+전화+이메일이 모두 있어도 각각 마스킹.**
- 별표(`*`) 영역 재마스킹·겹침 오류는 "span 수집 후 일괄 재조립" 방식으로 원천 차단.

### 이름 탐지 보정 (오탐 방지)
자유 텍스트 속 한글 이름은 일반 명사와 구분이 어려움 → 보수적 처리:
- 컬럼 전체가 "이름"으로 판정되면 → 해당 컬럼 셀은 이름 규칙 우선 적용.
- 자유 텍스트 셀에서는 **성씨 사전(약 100여 개) + 2~4자 경계 조건**을 만족할 때만 이름으로 탐지.
- 모든 결과는 화면에서 사용자가 검토·수정 가능.

## 4. 산출물 / UX

### 화면(앱)
- 컬럼별 미리보기에 **탐지 등급 배지(C/S/O)와 색상** 표시 (C=빨강, S=주황, O=회색).
- 셀 단위 다중 정보가 함께 마스킹된 미리보기 제공.

### 저장 파일(.xlsx) — 2개 시트
1. **`마스킹결과`** 시트: 원본 구조 그대로, 값만 등급별 마스킹.
2. **`분류리포트`** 시트: 감사 추적용.
   | 컬럼명 | 탐지된 정보유형 | 등급 | 건수 | 마스킹 정책 |
   |--------|----------------|:---:|:----:|-------------|

## 5. 구현 단계

| 단계 | 내용 |
|:---:|------|
| **P1** | `ENTITY_RULES`(유형·등급·정규식·마스킹함수) 데이터 테이블 + 등급별 마스킹 함수 |
| **P2** | 셀 단위 다중 엔티티 스캐너(`mask_cell`) — span 수집·충돌해소·재조립 |
| **P3** | 컬럼/셀 등급 집계 → 화면 등급 배지·색상 UI |
| **P4** | 저장 시 `마스킹결과` + `분류리포트` 2시트 출력 |
| **P5** | 성씨 사전·이름 보정, 엣지케이스(빈 셀·숫자형 셀) 테스트 |

---

## 6. 적용 결정 사항 (확정)
- **마스킹 범위:** 등급별 차등 (C=완전, S=부분, O=유지)
- **등급 표현:** 화면 미리보기 + 저장 파일 분류리포트 시트 둘 다
- **다중 정보 탐지:** 전체 셀 자동 스캔
