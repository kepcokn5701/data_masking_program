파일은 처리 즉시 서버에서 삭제됩니다 · N2SF 등급은 참고 분류, 핵심은 마스킹

📖 사용법

올리기 → 확인 → 다운로드. 여러 파일도 한 번에 처리됩니다.

① 올리기 → ② 확인 → ③ 다운로드

  1. 엑셀(.xlsx) 파일을 올립니다(여러 개 가능). 파일마다 카드로 분류 결과가 나옵니다.
  2. 컬럼별 등급(C/S/O)·오탐 추정 %·“원본 → 마스킹” 미리보기를 확인하고 체크를 조정합니다.
  3. 하단 [분류 결과와 오탐 가능성을 확인했습니다]에 체크하면 버튼이 켜집니다 → [마스킹 다운로드](1개=엑셀, 여러 개=ZIP). [초기화]로 처음부터 다시.

⚠ 오탐 가능성은 “확률 + 근거”로 알려드립니다

각 탐지에 추정 오탐 %를 색으로 표시합니다 — 낮음 보통 높음. 규칙 강도 기반 추정치이며, 왜 그 수치인지 근거를 하단 패널에 함께 보여줍니다(사람이 판단·소명할 수 있도록).

  • 낮음(주민·카드·면허·전화·이메일·계좌·차량): 검증 로직이 있어 오탐이 드뭅니다.
  • 보통~높음(이름·주소·여권·생년월일): 자동 판정 특성상 누락·오탐이 생길 수 있습니다.
  • 다운로드 전 확인 체크가 필수입니다(검토 없이 받을 수 없게).
